Project Overview & Mission

Problem Statement

Flash floods in the Himalayan river basins — particularly in Uttarakhand, Himachal Pradesh, and Sikkim — are among the most catastrophic natural disasters in India. Events like the Kedarnath 2013 Cloudburst, the Chamoli 2021 Glacier Lake Outburst Flood (GLOF), and the Wayanad 2024 Monsoon Surge have collectively claimed thousands of lives and caused billions in infrastructure loss. These disasters share a critical common failure: insufficient warning lead time and lack of automated, physics-informed early detection systems.

Traditional hydrometeorological monitoring relies on manual gauge readings, siloed government databases, and models that cannot run in real time at the edge. HydroSentinel AI™ was built to close this gap — delivering an autonomous, 24/7 flash flood early warning and simulation platform that fuses physics, machine learning, satellite remote sensing, and real-time open-source data meshes.

Machine Learning Pipeline

Input Feature Set — 10 Telemetry Inputs

The ML model accepts exactly 10 real-time hydrological and geomorphological parameters measured by IoT sensors deployed at Himalayan basin stations:

# Feature Name Unit Range Physical Meaning
1elevation_mmetres100–5000Station altitude above sea level
2slope_gradient_degdegrees0–60Terrain slope angle — steeper = faster runoff
3rainfall_intensity_mm_hrmm/hr0–250Instantaneous precipitation rate (cloudburst: >50 mm/hr)
4cumulative_rainfall_24h_mmmm0–600Total 24-hour basin accumulation
5soil_moisture_percentage%0–100Bedrock saturation (critical: >80%)
6river_water_level_mmetres0–15River stage height at gauge station
7river_flow_velocity_mpsm/s0–12Lateral flow speed in channel
8upstream_basin_surge_ratem³/s²0–10Rate of inflow acceleration from upper catchment
9vegetation_ndviindex0.1–0.9Canopy cover (lower = less runoff absorption)
10drainage_density_km_km2km/km²0.5–8.0Channel network density — higher = faster flash response

Feature Engineering: Hydrological Physics

The HydrologicalFeatureEngineering transformer (a custom sklearn TransformerMixin) derives 3 additional physics-informed features before scaling:

① Runoff Kinetic Surge

Represents the kinetic energy of surface water movement combining velocity and slope angle.

runoff_surge = velocity × sin(slope_gradient_deg in radians)

② Hydro-Saturation Index

Quantifies how much additional rainfall the soil can still absorb before runoff begins.

hydro_sat = (soil_moisture_pct / 100) × cumulative_rainfall_24h_mm

③ Instantaneous Flash Load

Combines intensity and slope to estimate the immediate surface runoff loading.

flash_load = rainfall_intensity_mm_hr × (slope_gradient_deg / 20.0)

This results in a 13-dimensional feature vector (10 raw + 3 derived) that is then scaled via StandardScaler.

Model Training & Ensemble Selection

Five different regression models are trained in parallel and evaluated. The best performer by R² score is automatically selected and saved as artifacts/model.pkl:

Model Algorithm Key Hyperparameters Typical R²
XGBoost ⭐ (Champion) Gradient Boosted Trees n_estimators=130, lr=0.08, max_depth=5 ~0.986
Random Forest Bagged Decision Trees n_estimators=120, max_depth=12 ~0.978
Gradient Boosting Sequential Boosting n_estimators=140, lr=0.08, max_depth=5 ~0.972
Extra Trees Extremely Randomised Trees n_estimators=100, max_depth=12 ~0.965
Ridge Regression Regularised Linear alpha=1.0 ~0.82
⚠️ Quality Gate: If the best model achieves R² < 0.70, training is aborted with a CustomException. This ensures only statistically valid models are deployed.

Security & Enterprise Architecture

Security Headers Middleware

Every HTTP response from HydroSentinel is decorated with hardened security headers via Flask's @app.after_request hook:

HeaderValuePurpose
HSTSmax-age=31536000; includeSubDomainsForce HTTPS for 1 year
X-Content-Type-OptionsnosniffPrevent MIME type sniffing
X-Frame-OptionsSAMEORIGINClickjacking protection
X-XSS-Protection1; mode=blockXSS filter enforcement
Content-Security-Policydefault-src 'self' ...Injection attack prevention

Circuit Breaker Pattern

The CircuitBreaker class wraps AI prediction endpoints to prevent cascade failures:

CLOSED
Normal Operation — All requests pass through
HALF-OPEN
Recovery Probe — One test request allowed after 15s
OPEN
After 3 failures — 503 returned immediately

Structured JSON Logging

All events are logged as machine-parseable JSON using a custom JSONFormatter — compatible with ELK Stack (Elasticsearch / Logstash / Kibana) and Datadog ingestion:

{
  "timestamp":  "2026-09-21 00:42:35,000",
  "level":      "INFO",
  "module":     "predict_pipeline",
  "msg":        "Best Model Selected: XGBoost with R2: 0.9858"
}

Admin Authentication

The API Explorer and admin panel are protected via environment-variable-based session authentication. Login via POST /api/admin-auth sets a server-side session. Admin password is stored in ADMIN_PASSWORD environment variable.

Offline PWA Support

A registered Service Worker (static/sw.js) enables offline operation. The offline_disaster_storage.js module queues SOS reports in IndexedDB during network outages and auto-syncs upon reconnection.
